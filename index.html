WaterMelon YouTube Automation

A separate, local application that helps the WaterMelon channel owner publish authorized beat previews to @iamwatermelon7 on YouTube.

This app is used only by the channel owner and personally authorized operators. This website provides app information and policies; it does not provide a public sign-in or upload service.

What the app does

  • Reads a limited amount of public WaterMelon beat information, preview audio and seller artwork.
  • Creates a visualizer video locally, with the seller's title and credit, relevant English metadata and a link to the beat's purchase page.
  • Uses the YouTube Data API to upload privately, check processing, set the thumbnail, and apply the owner's chosen visibility.
  • Rechecks sale availability and makes a video private when its source beat is confirmed unavailable. Checks are periodic, so changes are not immediate.
  • Preserves publishing history to avoid duplicate uploads, with bounded retries and operator pause controls.

Google authorization

The owner authorizes the app through Google's OAuth screen. The app requests the youtube.force-ssl permission for the channel checks, video uploads and status changes it performs. It does not ask for the owner's Google password or sign-in cookies.

The worker runs on the owner's separate computer. It does not run inside the WaterMelon website, connect to the service's database, or change checkout, accounts or the player. Media rendering and YouTube uploads use the separate computer.
