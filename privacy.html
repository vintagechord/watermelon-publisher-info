Privacy policy

Effective October 16, 2026. This policy describes WaterMelon YouTube Automation, a local application used by the WaterMelon channel owner and personally authorized operators. The app uses YouTube API Services. Google's processing is described in the Google Privacy Policy.

Information accessed and why

  • Google authorization: OAuth client information and a refresh token let the app access the approved channel. An access token is kept in process memory. The app does not collect Google passwords or sign-in cookies.
  • YouTube data: channel and video identifiers, ownership, processing and visibility information support safe uploads, channel verification, status changes and duplicate prevention. The app stores identifiers, temporary upload-session references and verification timestamps, rather than full API responses.
  • Independent source material: public WaterMelon beat metadata, preview audio and seller artwork are used to create authorized promotional videos. Generated media, upload metadata and source-product publishing records are separate from YouTube API data.

The app requests youtube.force-ssl only for its implemented channel checks, uploads, thumbnails and visibility changes. It does not collect viewer or subscriber lists, comments, analytics or advertising profiles.

Use, sharing and storage

Google receives the authorization requests, uploaded videos, artwork and metadata needed for the owner's selected YouTube actions. Public videos and their metadata become visible according to the privacy setting chosen by the owner.

The worker's files and state database are stored on the owner's separate computer. OAuth credentials use a private file, and access to the worker's state is restricted to the owner and approved operators. This documentation site does not receive the worker's tokens, media or database.

Google user data is not sold, used for advertising, used to train generalized AI models, or transferred for unrelated purposes. WaterMelon YouTube Automation's use and transfer of information received from Google APIs adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

When publishing is enabled and the worker is running, it rechecks authorization and channel ownership daily. Stored video IDs become due for refresh after 20 days, with at most two batches of 50 IDs per UTC day. Identifiers and upload sessions that cannot be refreshed are retired locally at 29 days. Finished videos no longer need their upload-session references.

Local expiry still runs when a running worker is paused or publishing is disabled. A computer that is off cannot perform scheduled work; its operator must run maintenance or remove expired API data within 30 days. Regenerable media for completed jobs is normally cleaned up after seven days.

The disconnect command requests Google token revocation. After successful revocation, it removes the local token and Google-derived identifiers, sessions and API history. A definite response that the refresh grant is invalid also pauses the worker and removes the affected token and API data. Temporary network or generic permission errors do not themselves erase current records; the retention deadline still applies.

You can revoke access through Google's connected-app permissions. The next successful authorization check detects a revoked grant. You can also ask the channel owner to delete locally stored Google data; the owner will handle the request as soon as possible and within seven calendar days. Any operator-created credential copies or backups must follow the same deletion policy.

Independent source-product IDs and publishing-attempt records remain to prevent accidental reposting after Google data is removed. They do not retain the deleted Google channel, video or session identifiers. Deleting this app's local data does not delete videos already stored by YouTube; those can be managed in YouTube Studio.

This documentation website

These static pages do not set application cookies or include advertising or analytics scripts. They are hosted by GitHub Pages, which logs visitor IP addresses for security. See the GitHub Privacy Statement.

Contact and updates

For privacy questions, complaints or deletion requests, contact the WaterMelon channel owner using the public contact information available on the channel's About page. Material changes to the app's data practices will be reflected here before new data uses begin.
